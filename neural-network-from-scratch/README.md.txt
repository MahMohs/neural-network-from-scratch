# Neural Network From Scratch

A simple fully-connected neural network implemented from scratch using Python and NumPy.

The goal of this project is to understand the fundamental mechanics of neural networks before using deep learning frameworks such as PyTorch.

## Architecture

```text
Input (2)
   ↓
Linear Layer (4 neurons)
   ↓
ReLU
   ↓
Linear Layer (1 neuron)
   ↓
Output
